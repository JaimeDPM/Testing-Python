# Learning Python

Progressive exercises to learn Python from scratch. Each folder is a topic.

## How to use this

1. Go into the topic folder (e.g. `01_variables`)
2. Read the `lesson.md` file — it explains the theory with examples
3. Open `exercise.py` and complete what's asked where it says `# TODO`
4. Run your code from the terminal:
   ```
   python 01_variables/exercise.py
   ```
5. Once it works, move on to the next topic
